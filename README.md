# 🎓 AI University Calendar Manager

Este es un bot en Python que automatiza la gestión de mi horario universitario. Utiliza la API de Gmail para leer avisos de profesores y Gemini 2.5 Flash para extraer estructuradamente cambios de clase, exámenes o cancelaciones. Finalmente, actualiza Google Calendar automáticamente.

## Tecnologías usadas
- Python 3
- Google Calendar API & Gmail API
- Google GenAI (Gemini 2.5 Flash)
- Desplegado en Google Cloud (Compute Engine)
